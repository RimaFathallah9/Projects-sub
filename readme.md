1. **AI-Driven Modeling of Neuroplasticity Trajectories in Pediatric Cerebral Palsy**
2. **Facial Expression Recognition Using Deep Learning**

## 1. AI-Driven Modeling of Neuroplasticity Trajectories in Pediatric Cerebral Palsy

This research project explores how artificial intelligence can support the analysis of neuroplasticity trajectories in children with cerebral palsy (CP). The goal is to better understand patterns of development, improve predictions of future outcomes, and contribute to a deeper understanding of how recovery and adaptation may evolve over time.

My motivation for this work comes from the unequal availability of resources and medical knowledge in low-resource settings. Children with cerebral palsy face serious health and developmental challenges, particularly in countries where specialized expertise and support systems are limited. Although my motivation is informed by experiences in Tunisia, this issue affects many communities around the world.

The future development of cerebral palsy remains complex and difficult to predict. Researchers use hypotheses and computational models to investigate possible trajectories, but uncertainty remains. This project aims to examine the problem through a research and AI-driven approach, with the hope of developing useful insights that can support future studies and potentially improve patient outcomes.

## 3. Facial Expression Recognition Using Deep Learning

This project is a simple deep learning application for facial expression recognition. It demonstrates how a machine learning model can classify a facial expression from an image.

The project is intended as an introductory and educational example of:

- Image preprocessing
- Convolutional neural networks
- Facial feature classification
- Deep learning model training and evaluation
